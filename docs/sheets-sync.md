# Google スプレッドシートへの自動反映

BookNest で **フレーズ・知識・創作メモ** を保存・編集・削除すると、Google スプレッドシートに自動で反映されます。
スプレッドシート側に小さなスクリプト（Apps Script）を置き、BookNest からそこへデータを送る仕組みです。Google Cloud の設定は不要です。

## シートの構成

スクリプトが次の3つのシートを自動で作ります（既存のシートはそのまま残ります）。1列目の ID で行を特定するので、**ID 列は消したり並べ替えたりしないでください**。それ以外の列の幅や色、フィルタは自由に変えて構いません。

| シート | 列 |
| --- | --- |
| フレーズ | ID / フレーズ / 本 / 著者 / ページ / メモ / タグ / お気に入り / 登録日 / 更新日 / リンク |
| 知識 | ID / タイトル / 内容 / カテゴリ / タグ / 関連する本 / 登録日 / 更新日 / リンク |
| 創作メモ | ID / タイトル / 内容 / 種類 / 状態 / タグ / 元になった資料 / 使っている作品 / 登録日 / 更新日 / リンク |

- 日時は日本時間です。
- 「リンク」は BookNest の該当ページへのリンクです（`APP_URL` を設定した場合は完全な URL になります）。
- シート上で直接編集した内容は、BookNest 側で同じデータを保存したときに上書きされます。**編集は BookNest で行ってください**（スプレッドシートは閲覧・集計用）。

## 設定手順（10分ほど）

### 1. 合言葉（シークレット）を作る

BookNest とスプレッドシートが同じ合言葉を持つことで、他人からの書き込みを防ぎます。PC のターミナルで次を実行し、表示された文字列を控えます。

```bash
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
```

### 2. スプレッドシートにスクリプトを置く

1. 反映先のスプレッドシートを開き、メニューの **拡張機能 → Apps Script** を開きます。
2. 最初からある `コード.gs` の中身をすべて消し、このリポジトリの [`docs/sheets-sync/Code.gs`](sheets-sync/Code.gs) の内容を貼り付けて保存（💾）します。
3. 左の ⚙️ **プロジェクトの設定** → 下の方の **スクリプト プロパティ** →「スクリプト プロパティを追加」
   - プロパティ：`SECRET`
   - 値：手順1の合言葉
4. 右上の **デプロイ → 新しいデプロイ** → 種類の選択（⚙️）で **ウェブアプリ** を選び、
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   として **デプロイ** します。初回は Google アカウントへのアクセス許可を求められるので、内容を確認して許可します（「このアプリは Google で確認されていません」と出た場合は「詳細」→「（安全ではないページ）に移動」）。
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーします。

> 「全員」にしても、合言葉を知らない人は書き込めません。URL と合言葉は他人に教えないでください。

### 3. BookNest に設定する

**PC（ローカル）で使う場合**：`.env` に追記して BookNest を再起動します。

```
SHEETS_WEBHOOK_URL=（手順2-5のURL）
SHEETS_WEBHOOK_SECRET=（手順1の合言葉）
# 任意：シートのリンク列を完全なURLにする
APP_URL=https://（あなたのBookNestのURL）
```

**クラウド（Vercel）で使う場合**：Vercel のプロジェクト → Settings → Environment Variables に同じ3つを追加し、Deployments から **Redeploy** します。

### 4. 動作確認と初回の書き出し

BookNest の **設定 → スプレッドシート連携** で

1. **接続テスト** →「接続できました」と出れば OK
2. **全件を書き出す** → これまでのデータがすべてシートに入ります

以降は、保存・削除のたびに数秒以内に自動で反映されます。

## うまくいかないとき

| 表示 | 対処 |
| --- | --- |
| 合言葉が一致しません | スクリプト プロパティ `SECRET` と `SHEETS_WEBHOOK_SECRET` が同じか確認 |
| 想定外の応答がありました | ウェブアプリの「アクセスできるユーザー」が「全員」か、URL が `/exec` で終わっているか確認 |
| スクリプトを直したのに変わらない | Apps Script の **デプロイ → デプロイを管理 → ✏️ → バージョン：新バージョン → デプロイ** で更新（URL は変わりません） |
| シートの行を消してしまった・内容がずれた | 設定画面の「全件を書き出す」で最新の状態に書き直せます |

自動反映に失敗しても、BookNest のデータ自体は保存されています（失敗はサーバーのログに記録されます）。
